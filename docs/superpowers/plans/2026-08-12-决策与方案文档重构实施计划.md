# 决策与方案文档重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使立项申请、方案调研、产品设计和架构设计各自只回答一个核心问题，并通过链接形成从决策到规范的阅读链路。

**Architecture:** 四份文档分别承担投资决策、路径选择、用户协作与系统实现边界。细节只在一个权威文档中完整出现：命令归 CLI 参考，任务状态归任务模型规范，输入与快照归上下文和连接器规范，安全边界归安全规范。

**Tech Stack:** Markdown、Git、`rg`、`git diff --check`

## Global Constraints

- 不改变四份目标文档的名称：立项申请、方案调研、产品设计、架构设计。
- 不改变已经确认的产品定位：`aiw` 是 Git 原生的 AI 研发变更治理层。
- Trellis 只能表述为能力对标对象或低治理要求的降级选项，不表述为 `aiw` 的同级替代方案。
- 不新增或变更产品能力、CLI 行为和专项规范；本次只重构决策与方案层的表述和链接。
- 不在产品设计中保留具体 CLI 命令，不在架构设计中重复完整选型辩论。
