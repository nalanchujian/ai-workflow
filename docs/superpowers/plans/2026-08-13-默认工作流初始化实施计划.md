# 默认工作流初始化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `aiw init` install the official default workflow and let task creation use it without a manually supplied profile.

**Architecture:** Store only the intended official source ref and profile in `LocalConfig`; compose `LocalInitializer`, `SkillInstaller`, and `SkillRegistry` in a bootstrap service that reports whether it installed or reused the profile. Task creation resolves the default from config only when the caller does not provide an explicit profile. A dedicated update command installs first and changes the config ref only on success.

**Tech Stack:** TypeScript, Zod, YAML, Commander, Vitest.

## Global Constraints

- Never modify an existing task's locked skills or task facts.
- Never update the configured default ref before the requested skills package installs successfully.
- Do not create Git commits, tags, pushes, or npm publications without explicit user direction.
