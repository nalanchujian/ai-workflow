# 文档阶段目录重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 aiw 的正式文档迁移为按七个项目阶段组织的目录，并保持所有 Markdown 链接有效。

**Architecture:** 使用 Git 重命名保留文件历史，正式文档进入 `01` 至 `04` 阶段目录，重构过程记录进入 `00-工作记录`。README 成为七阶段导航，`05` 至 `07` 只说明后续文档缺口，不创建空目录。

**Tech Stack:** Markdown、Git、`rg`、`git mv`、`git diff --check`

## Global Constraints

- 不改变任何正式项目文档的名称、标题或正文内容。
- 不创建 `05-开发实现`、`06-测试验证`、`07-发布运营` 空目录。
- 不在 README 的正式项目文档导航中展示 `00-工作记录`。
- 所有相对 Markdown 链接在迁移后必须指向存在文件。
- 使用 `git mv` 执行文件迁移，保留历史。

done
