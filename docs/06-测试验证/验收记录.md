# MVP 验收记录

## 用途

本文记录当前代码对《MVP需求与验收规范》中 AC-1 至 AC-25 的自动化验证证据。产品通过标准仍以《MVP需求与验收规范》为唯一权威；本文不新增或修改验收条件。

## 自动化验证命令

```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm build
```

测试使用临时目录及 Git、网络、MCP、Codex 进程替身；不会访问真实公网、Lark 文档或 Codex 服务。

## 内置方法依赖补充证据

- `tests/domain/bundled-method-source.test.ts`：校验内置方法清单、上游 commit、许可证与安装记录格式。
- `tests/services/skill-registry.test.ts`：Registry v2 保存内置方法，并在同一团队来源更新时原子替换。
- `tests/services/method-source-resolver.test.ts`：运行时只从 Registry 读取与锁定字段完全一致的内置方法，不读取本机 Superpowers 目录。
- `tests/services/local-initializer.test.ts`、`tests/cli/init-command.test.ts`：`aiw init` 创建仅含可选连接器的安全模板，并且不覆盖已有文件。
| AC-25 | `tests/cli/task-state-commands.test.ts`、`tests/services/task-state-machine.test.ts`：`request-changes` 保留审批和修订事实并失效下游。 |

## 当前结论

本记录对应的自动化套件在当前实现中通过。真实 Lark 授权、真实 Codex CLI 与真实 Git 托管权限属于本机运行前置条件，需在试点环境另行验证，不由替身测试模拟为已授权状态。
