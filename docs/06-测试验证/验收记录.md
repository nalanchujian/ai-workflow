# MVP 验收记录

## 用途

本文记录 AIW 产品自身的自动化验证范围。它不表示 AIW 会为用户业务代码执行测试或验收。

## 验证命令

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm pack:check
git diff --check
```

## 当前证据范围

- 来源：本地文件、公开 URL、连接器路由、章节读取和刷新。
- 澄清：事实登记与决策登记 Schema，逐项本期/延期选择。
- 方案和计划：最小上下文、结构化开发计划、旧复杂字段拒绝。
- 开发单元：计划物化、依赖解锁、循环依赖拒绝、独立 worktree 和补丁发布。
- 状态：节点迁移、重跑、下游失效、任务锁、`stateVersion` 和开发进度汇总。
- 技能：模板映射、内置方法来源、技能正文协议边界。
- CLI：初始化、doctor、任务创建、运行、review、approve、status、来源刷新和运行历史。

测试使用临时目录以及 Git、网络、MCP、Codex 替身，不访问真实公网、真实在线文档或真实 Codex 服务。真实环境试用仍需单独检查 Git、Codex、文档权限和业务仓库行为。

## 当前结论

只有完整验证命令全部通过后，才能声明 AIW 软件包满足当前 MVP 自动化基线。最终“可以用于真实试用”还需要一条从真实需求来源到开发单元完成的人工冒烟流程。
