# MVP 验收记录

## 用途

本文记录《MVP需求与验收规范》中 AC-01 至 AC-07 的自动化验证证据。产品通过标准以该规范为唯一权威。

## 验证命令

```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm build
```

测试使用临时目录以及 Git、网络、MCP、Codex 进程替身；不会访问真实公网、受控在线文档或 Codex 服务。

## 证据映射

| 验收 | 自动化证据 |
|---|---|
| AC-01 来源可信 | `tests/services/source-intake.test.ts`、`source-refresher.test.ts`、`source-snapshot-integrity.test.ts`：来源路由、安全边界、快照 revision 和 SHA-256 失配拦截。 |
| AC-02 需求结论可确认 | `tests/domain/decision-register.test.ts`、`tests/services/task-decision-service.test.ts`、`tests/cli/task-state-commands.test.ts`：逐项决策、人工结论、外部等待和审批事实。 |
| AC-03 计划可执行 | `tests/services/implementation-work-planner.test.ts`、`tests/cli/task-state-commands.test.ts`：唯一 AC 覆盖、单元依赖和计划批准后的 `delivery-*` 节点生成。 |

## 当前结论

本记录对应的自动化套件通过。真实 Lark 授权、真实 Codex CLI 与真实 Git 托管权限属于试点环境前置条件，需要另行验证。
