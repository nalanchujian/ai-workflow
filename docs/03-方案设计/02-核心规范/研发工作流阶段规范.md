# 研发工作流阶段规范

```text
requirement-analysis → task inputs → [api-analysis] → [design-slicing] → solution → plan → development-unit-*
```

| 阶段 | 输入 | 输出 |
| --- | --- | --- |
| requirement-analysis | 需求快照 | 事实与决策登记 |
| api-analysis | 接口文档快照 | 接口分析 |
| design-slicing | 一张任务内图片 | 裁切资产与索引 |
| solution | 事实、决策、可选接口分析 | 技术方案 |
| plan | 方案、可选接口与设计资产 | 开发计划与动态单元 |
| development-unit-* | 单元上下文及绑定资料 | 代码修改与开发结果 |

仅需求决策需要人工处理。任何资料节点均可选，但资料选择本身必须完成后才可运行方案。
