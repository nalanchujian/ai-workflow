# 研发工作流阶段规范

```text
requirement-analysis → task review → api-analysis → design-slicing → solution → plan → development-unit-*
```

| 阶段 | 输入 | 输出 |
| --- | --- | --- |
| requirement-analysis | Lark 需求快照，可选章节 | 事实与决策登记 |
| task review | 事实与决策登记 | 人工审核记录和已确认决策 |
| api-analysis | 零个或多个 YApi 文档快照 | 接口分析；未提供资料时直接通过 |
| design-slicing | 零张或一张任务内图片 | 裁切资产与索引；未提供资料时直接通过 |
| solution | 事实、决策、可选接口分析 | 技术方案 |
| plan | 方案、可选接口与设计资产 | 开发计划与动态单元 |
| development-unit-* | 单元上下文及绑定资料 | 代码修改与开发结果 |

技术方案不读取设计切割结果。计划和开发不使用人工批准状态。
