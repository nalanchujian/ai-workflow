# 技能包规范

`standard-web-feature` 必须声明六个阶段：`requirement-analysis`、`api-analysis`、`design-slicing`、`solution`、`plan`、`development`。每个阶段的技能绑定是非空列表：一个引用表示一对一，多个引用表示一对多；所有技能和模板使用 `aiw.task-output/v2`。

技能全部在团队技能仓库内自定义，描述方法与边界，不能固化 AIW 物理路径、Schema 或产物字段。运行时协议是唯一的字段定义来源。

- 需求分析只读需求快照。
- 接口分析只读接口快照。
- 设计切图只切图和建索引。
- 方案不读设计资料。
- 计划绑定真实接口和图片 ID。
- 开发单元只使用自身上下文和绑定图片。
