# 上下文包规范

上下文按节点显式组装，不会批量注入全部任务来源。

| 节点 | 允许输入 |
| --- | --- |
| requirement-analysis | 需求快照 |
| api-analysis | 所有接口文档快照 |
| design-slicing | 单张任务内设计图 |
| solution | 事实登记、决策登记、可选接口分析 |
| plan | 技术方案、可选接口分析、可选设计资产索引 |
| development-unit-* | 当前单元 YAML 与它引用的设计截图 |

技术方案不接收设计原图、设计索引或裁切资产。开发单元从上下文中的接口引用取得对应文档 ID 与快照路径。
