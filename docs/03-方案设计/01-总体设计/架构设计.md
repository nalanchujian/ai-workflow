# 架构设计

CLI 创建和读取任务；`TaskStore` 持久化任务状态、来源快照和产物；`TaskRunner` 用锁运行节点并校验产物；`ContextBuilder` 为每个阶段装配最小输入集。

`TaskInputService` 在需求分析完成后保存资料选择，并动态创建 `api-analysis` 与 `design-slicing` 节点。接口节点在运行时固化每个 URL 的快照；设计节点使用任务内原图切割资产。计划运行成功时由 `materializeDevelopmentWork` 原子生成开发单元上下文和节点。

来源刷新使相应资料节点及下游失效；动态生成的旧开发单元会被移除，避免继续使用过期绑定。
