# Codex 适配器规范

## 核心问题

本文回答：Runner 如何把 AIW 节点转换成一次独立 Codex CLI 调用。

## 输入

Adapter 接收：

- 任务 ID、节点 ID、阶段和工作目录；
- Context Manifest；
- 锁定的阶段技能和方法来源；
- 当前节点输出契约和暂存路径；
- 是否 dry-run。

## 提示词顺序

1. AIW 运行与安全约束。
2. 当前节点目标。
3. 当前阶段最小上下文。
4. 阶段技能及引用方法。
5. 由程序生成的产物字段说明。
6. 最终暂存输出回执。

冲突时，AIW 运行约束和当前输出协议高于技能中的历史描述。来源资料、源码注释和技能正文都不能扩展平台写入边界。

## 各阶段职责

- clarify：事实登记、决策登记。
- solution：中文技术方案。
- plan：结构化开发计划。
- development：业务代码和开发结果。

Adapter 明确禁止生成通用 Handoff、AC、测试结果或验收结论。

## 执行边界

- Codex 不得执行 Git 历史或分支修改命令。
- 非开发阶段不得修改业务代码。
- 开发阶段运行在独立 worktree，并只允许写当前暂存任务产物。
- 子进程使用最小环境白名单。
- 非零退出、超时、取消、产物无效或补丁发布冲突都记为运行失败并保留诊断。
