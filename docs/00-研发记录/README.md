# 研发记录

本目录保存 `aiw` 自身的历史设计与实施记录，供维护者追溯当时的决策、实现顺序和验证过程。

```text
设计/       # 设计边界、架构取舍与产品行为的历史说明
实施计划/   # 已执行功能的任务拆分、测试与验证记录
```

这里不是 Superpowers 文档目录，也不承载团队技能包的内容。Superpowers 方法正文、来源清单、许可证、阶段技能、工作流模板及其发布指南均由独立的 `ai-workflow-skills` 仓库维护。

当前生效的产品和技术规则以 `docs/01-立项与规划` 至 `docs/07-发布运营` 中的正式文档为准；本目录仅提供历史背景，若两者存在差异，以正式文档为准。
