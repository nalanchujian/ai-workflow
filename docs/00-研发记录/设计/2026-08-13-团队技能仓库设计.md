# 团队技能仓库设计（v1 历史记录）

> 本文记录已发布的 `v1.0.0` 方案。新用户流程和当前技能包结构以《[内置方法依赖设计](2026-08-13-内置方法依赖设计.md)》与《[技能包规范](../../03-方案设计/02-核心规范/技能包规范.md)》为准；v2 不再要求用户配置 Superpowers。

## 目标

建立公开 GitHub 仓库 `nalanchujian/ai-workflow-skills`，作为 AI Workflow 的真实团队技能来源。普通用户安装 `@nalanchujian/ai-workflow` 后，应能安装该仓库并选择 `standard-web-feature` 模板创建任务。

## 边界

- 仓库只分发声明式 Markdown 技能与工作流模板，不包含可执行脚本、密钥或业务源码。
- 仓库不复制 Superpowers 正文；每项技能只引用对应的已配置方法来源，并补充 AIW 的输入、产物、禁止事项与验证要求。
- 本次只提供一个面向 TypeScript Web 业务需求的标准模板，不扩展 CLI、任务模型或审批策略。

## 仓库结构

```text
ai-workflow-skills/
├── README.md
├── skills/
│   ├── requirements-clarification/SKILL.md
│   ├── technical-solution/SKILL.md
│   ├── implementation-planning/SKILL.md
│   ├── typescript-web-implementation/SKILL.md
│   ├── web-verification/SKILL.md
│   └── acceptance-testing/SKILL.md
└── profiles/
    └── standard-web-feature/PROFILE.yaml
```

## 模板与技能映射

| 阶段 | 技能 | 方法来源 | 必须产物 |
| --- | --- | --- | --- |
| clarify | `requirements-clarification@1.0.0` | `superpowers:brainstorming@6.2.0` | `brief.md`、`questions.md`、`acceptance.md` |
| solution | `technical-solution@1.0.0` | `superpowers:brainstorming@6.2.0` | `solution.md` |
| plan | `implementation-planning@1.0.0` | `superpowers:writing-plans@6.2.0` | `implementation-plan.md` |
| implement | `typescript-web-implementation@1.0.0` | `superpowers:test-driven-development@6.2.0` | `implementation.md` |
| verify | `web-verification@1.0.0` | `superpowers:test-driven-development@6.2.0` | `verification.md` |
| test | `acceptance-testing@1.0.0` | `superpowers:test-driven-development@6.2.0` | `test-report.md` |

每个 `SKILL.md` 使用 AIW 技能包规范要求的 front matter 与“输入、步骤、验证”章节。模板将六个可执行阶段一一锁定到上述技能版本。

## 使用方式

```bash
aiw skills install https://github.com/nalanchujian/ai-workflow-skills.git
aiw skills profiles list
aiw task init --project <项目目录> --source <需求来源> --skill-profile standard-web-feature@1.0.0
```

安装器应记录 Git revision 与每个入口的哈希；任务初始化时再将模板、技能和方法来源锁定到任务事实。

## 验收

1. 公开仓库可通过 HTTPS 克隆。
2. 六项技能与一个模板均通过现有 `aiw skills install` 校验。
3. `aiw skills profiles list` 显示 `standard-web-feature@1.0.0` 及完整六阶段映射。
4. 可用该模板完成一次任务初始化；任务中锁定仓库 revision、技能哈希和 Superpowers 方法来源。
