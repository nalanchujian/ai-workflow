# Agent 产物协议单一来源实施计划

> **文档状态：历史研发记录。** 本文记录当时的实施步骤和验证结果，不是当前实现指南。现行行为以正式规范、CLI 帮助和当前代码为准。

**目标：** 让 Zod Schema 与程序化协议描述成为 Agent 产物格式的唯一来源，消除 Adapter 提示词和技能包中的手写 Schema、示例与物理路径副本。

**架构：** 新增 Agent 产物协议目录，每项协议绑定现有 Zod Schema、经 Schema 校验的 YAML 示例和必要语义规则，并统一渲染为紧凑提示词。Codex Adapter 只选择协议和注入当前 Output Contract 路径；技能包只描述方法、判断标准和质量要求。

**技术栈：** TypeScript、Zod 4、YAML、Vitest。

## 全局约束

- 不改变现有正式产物的 schemaVersion 和磁盘格式。
- 物理路径只来自 `aiw.task-output/v1`，不能写入技能。
- Agent 提示中的字段结构和 YAML 示例必须由协议目录生成，不能在 Adapter 中手写。
- 每个示例必须先通过对应 Zod Schema 校验。
- 保留业务语义约束，但集中在协议描述或工作流指令中，不能重复字段白名单。
- 不自动提交或 push。
