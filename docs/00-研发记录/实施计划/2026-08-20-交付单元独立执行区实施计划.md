# 交付单元独立执行区实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让每个交付单元在独立 Git worktree 中完成代码、测试和验收，并只在成功后将业务补丁发布到用户工作区。

**Architecture:** 新增独立的执行区端口与 Git 实现，Runner 只在计划生成的交付节点中启用。隔离 TaskStore 承载本次暂存产物，原 TaskStore 保存正式任务事实和运行证据；成功时发布排除 `.aiw` 的二进制补丁，失败时仅保存隔离区证据。

**Tech Stack:** TypeScript、Node.js、Git worktree、Vitest、Zod

**Spec:** `docs/00-研发记录/设计/2026-08-20-交付单元独立执行区设计.md`

## Global Constraints

- 只有 `generatedFromPlan: true` 的交付节点使用独立 worktree。
- 不自动提交、切换或推送用户分支。
- 失败、取消和测试不通过不得修改源业务工作区。
- `.aiw/` 永远不进入业务补丁。
- 源 HEAD 或业务工作区在运行期间变化时拒绝发布。
- 所有新增行为先写失败测试并确认按预期失败。
