# AIW 用户使用手册

## 初始化

```bash
aiw init
aiw doctor
```

## 创建并推进任务

```bash
aiw task init --project . --source "https://docs.example.com/requirements"
git add .aiw && git commit -m "chore(aiw): initialize task"
aiw task run <task-id> requirement-analysis
```

如果需求分析提出待决策事项，执行 `aiw task review <task-id>`，逐项选择本期方案或延期。没有待决策事项时节点会自动完成。

随后执行：

```bash
aiw task inputs <task-id>
```

命令会先问是否提供接口文档。选择提供时，每行输入一个 HTTP(S) URL，以空行结束。接着问是否提供设计图；选择提供时输入一张本地 PNG/JPEG 路径。回答会立刻保存，中断后再次执行同一命令继续。

按每次命令输出的下一步运行可选资料节点、技术方案和开发计划。计划成功后会自动生成 `development-unit-*` 节点，继续运行其中就绪的节点即可。无需执行 `task approve`。

## 提交任务事实

每个节点完成后，先按输出提示提交 `.aiw` 中的任务事实，再运行下一节点。来源或资料发生变更时，使用 `aiw task source refresh` 刷新对应快照，AIW 会使下游节点失效。
