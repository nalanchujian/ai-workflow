# 需求来源与关键决策

任务创建后，执行 `requirement-analysis --requirement-url <Lark文档URL>`，可选附带 `--section <章节名称>`。该节点读取并固化需求快照，事实登记只包含快照能直接确认的内容。

会影响本期实现、但无法由需求确定的问题进入决策登记。需求分析完成后必须运行 `task review`：待决策事项可选择本期方案或延期；没有待决策事项时，审核仍作为人工关口完成。

接口和设计资料分别由 `api-analysis` 与 `design-slicing` 节点参数传入，不是需求分析的输入，不能改变需求事实或决策范围。接口支持多个 `--api-url`；设计支持一个 `--design-image`。没有资料时使用 `--skip`，节点直接通过。
